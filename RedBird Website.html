About This Site

Learn more about the purpose and design of this website.

Purpose of the Website

This website was created as a three-section microsite. The welcome section introduces the project, the About section explains its design, and the Gallery displays visual examples.

The website uses Arial or Helvetica for regular text and Georgia for headings. These fonts create a clear difference between titles and paragraphs.

Design goal: Keep the pages consistent, the text readable, and the navigation easy to use.

Shared Design

Each section uses the same header, navigation bar, color palette, and footer. The red gradient makes the header stand out from the rest of the page.
